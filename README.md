# TMIS — Training Management Information System

TMIS (Training Management Information System) is a web-based application designed to help manage training programs, participants, evaluations, and administrative activities.

The system provides a centralized platform for managing training-related information and includes a dashboard for viewing training and participant statistics.

## 📌 About the Project

TMIS is built to organize and manage information related to training activities.

The system allows authorized users to manage:

- Training programs
- Participants
- Training evaluations
- Administrative information
- Training statistics
- Participant statistics

The dashboard provides visual representations of training and participant data, making it easier to monitor activities and compare yearly performance.

---

## ✨ Features

### 👥 Participant Management

- Create participant records
- Update participant information
- View participant details
- Manage participant-related information

### 📚 Training Management

- Create training records
- Update training information
- View training details
- Monitor training activities

### 📝 Evaluation Management

- Create and encode evaluations
- Update evaluation information
- View evaluation details
- Manage training evaluation data

### ⚙️ Administration

- Manage administrative information
- Update system-related records
- View administrative details

### 📊 Dashboard

The dashboard provides an overview of important training statistics, including:

- Total trainings
- Total participants
- Monthly training statistics
- Monthly participant statistics
- Municipality-based statistics
- Yearly comparisons

---

## 📈 Dashboard Charts

The dashboard uses interactive charts to display training and participant statistics.

### Total Trainings

The Total Trainings chart compares training activity between different years.

Users can click a year in the chart legend to:

- Hide that year's data
- Show the other year's data
- Click the year again to restore the hidden data
